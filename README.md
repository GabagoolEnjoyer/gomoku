# gomoku
Крестики-нолики 5 в ряд на 2 игрока, реализованные на Си

## Как использовать программу:
- Сперва выполняется команда make для компиляции сервера и клиента
- Затем на одном из трех терминалов запускается сервер через команду ./server
- (Если порт 8080 занят, убиваем процессы через sudo fuser -k 80/tcp)
- Далее идет запуск клиента на localhost ./client 127.0.0.1 8080
